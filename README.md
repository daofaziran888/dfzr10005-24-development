# 数仓治理与运维平台

面向数据仓库团队的治理与运维一体化平台。覆盖表生命周期管理、存储成本优化、数据热度分析、任务依赖编排、SLA告警、资源弹性调度与数仓健康度评估的完整治理链路。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 保留例外演练（retention_drill）

保留规则更新例外清单前，先做一次演练，提前发现哪些表会与生命周期清理、回收站恢复
窗口冲突，避免规则生效后数据被提前处理。领域代码集中在 `backend/app/retention_drill/`：

- `policy.py`：优先级与期限计算口径（合规权重、期限解析、范围匹配、双重命中裁决）；
- `engine.py`：演练冲突引擎，输出每张表的处置结果与冲突来源；
- `service.py`：状态机、幂等与并发控制、审计写入与治理清单同步。

关键规则：

- **处置三分类**：延期保留、转为归档、回收站保护，每条结果都带冲突来源（保留规则清理 /
  生命周期清理 / 回收站恢复窗口 / 例外双重命中）。
- **优先保留**：命中例外清单的数据优先保留；回收站可恢复期长于保留规则期限时，
  禁止直接永久清理（回收站页面对应动作会被拦截）。
- **双重命中裁决**：同一规则同时命中多条例外时，先按合规依据权重
  （法律法规 > 监管规定 > 行业标准 > 内控制度 > 业务约定 > 无）裁决，权重相同再取
  较长保留期，裁决依据完整记录在演练明细里。
- **可追溯**：演练单、审计依据（写入 `audit` 模块）、生命周期治理清单三处用同一
  演练单号串联；回收站记录回写保护来源，业务页面直接展示。
- **幂等与并发**：同一版本重复演练只保留一份有效演练单；同一数据集范围并发演练时，
  后到请求返回 409 被拒绝。
- **状态机**：例外规则严格按 草稿 → 生效 → 到期 → 废止 相邻前进，
  不允许回退或跳过中间状态。

验证脚本位于 `tests/`：`verify_retention_drill.py`（52 条服务级规则用例）与
`verify_http_409.py`（真实 HTTP 并发 409 用例），均用 `python -I` 运行。
